# INVICTUS BCA Attendance Tracker

A lightweight, offline-first attendance tracking web application designed for BCA Sec-B students.

INVICTUS helps students manage daily attendance, lecture-wise records, academic results, schedules, and attendance analytics from a single interface.

---

## ✨ Features

- 🔐 Student ID & Password login
- 📅 Daily attendance tracking
- 📚 Lecture-wise attendance marking
- 📊 Attendance percentage and analytics
- 🗓️ Attendance calendar
- 📈 Monthly and semester reports
- 📝 Subject Results
- 🧪 Class Test Results
- 📝 Surprise Test Results
- 📋 Exam Results
- 🔔 In-app attendance notifications
- 🕐 Daily timetable with date-based schedules
- 📖 Built-in User Guide
- 👤 Per-user profile and college joining-date support
- 💾 Local data persistence
- 📤 Data Export / Import
- 🌙 Light & Dark appearance
- 🔤 Adjustable Font Size
- 📱 Adjustable Display Size
- 📶 Offline-first functionality
- 📱 Android WebView compatible

---

## 🛠️ Technology

INVICTUS is built as a single-file web application using:

- HTML5
- CSS3
- JavaScript
- Local Storage
- IndexedDB

No external backend or database server is required for normal operation.

---

## 📱 Platform

INVICTUS is designed to work with:

- 💻 Desktop browsers
- 📱 Mobile browsers
- 🤖 Android WebView

The application is designed with offline usage in mind.
