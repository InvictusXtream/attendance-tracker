INVICTUS User Guide

Everything you need to use the app confidently.
Welcome to INVICTUS. This guide is a simple starting point for a new user. It explains what each main area does, what to tap, and how the app records your attendance, timetable changes, and results.

🚀 1. Getting Started

After signing in, complete the basic information INVICTUS requests, especially your College Joining Date. The main areas are Dashboard, Attendance, Semester, and Settings.

Record a college dayAttendance → Submit Your Attendance
Mark individual lecturesSemester → Daily Timetable
Manage submitted resultsSemester → All Submitted Results
Review progressDashboard

On the first successful login, the User Guide may open automatically. Scroll to the bottom and tap Close.

📅 2. College Joining Date

Your College Joining Date defines the earliest date for which INVICTUS lets you record your personal attendance.

Set it through Attendance → Submit Your Attendance when requested. Settings → App → Persistent Saving controls whether the date is retained after logout or Reset All App Data; it is ON by default.

📊 3. Submit Your Attendance

Use Attendance → Submit Your Attendance to record the status of a college day.

Select the available status for that date, such as Present, Absent, Holiday, or Blank, then complete the requested reason/details.

For a normal college day, use Present → Regular College Day. The attendance window controls when a Present submission can be made; submitting after the window is recorded as a Late Submission.

Before today's attendance is submitted, INVICTUS checks the isolated attendance records for all six semesters for prior unresolved eligible dates. If unresolved dates exist, the app routes you through the affected semester-wise resolution flow and returns to the target semester after the required dates are resolved.

The Attendance tab itself presents a unified read-only view assembled from the six isolated attendance stores. Attendance submission and editing remain scoped to the active semester store.

📚 4. Daily Timetable

Open Semester → Daily Timetable to see the lectures scheduled for the selected semester and date. Use the date controls, calendar, or swipe to move between days.

Tap a lecture's 3 dots to open its attendance actions:

AttendedRecords the lecture as attended. If an Adjustment is configured, its rules are applied.
AbsentRecords the lecture as absent.
Teacher AbsentRecords that the teacher was absent.
No ClassesRecords that the lecture did not take place.

🕐 5. Schedule Exception

Use Schedule Exception when the timetable for a particular college day is different from the normal schedule.

On an eligible Present → Regular College Day, tap the 🕐 clock to see that day's scheduled lectures. Tap a lecture to choose Set Replacement or Set Adjustment.

Set ReplacementChanges which lecture occupies that timetable slot.
Set AdjustmentKeeps the scheduled lecture for timetable/lecture tracking but sends the attendance credit to the selected subject when marked.

Replacement changes are confirmed before they are applied. After applying one, Schedule Exception reopens and shows the updated lecture. Other lecture slots are unchanged.

🔄 6. Adjustment Period

Use an Adjustment when you attended a different subject during a scheduled lecture period.

Go to Daily Timetable → 🕐 Schedule Exception → Lecture → Set Adjustment. Choose from Subjects, Lab, or Others, select the class, then tap Apply.

The selection list scrolls inside the dialogue. When an Adjustment is used for attendance, the original scheduled lecture remains the tracked lecture and is recorded as Teacher Absent, while the selected adjustment subject receives the attendance status you choose.

When editing an existing Adjustment, selecting the original scheduled subject removes that Adjustment.

↩️ 7. Set to Default

Use Set to Default inside Schedule Exception when you want to remove a timetable change for that date.

If both types exist, choose what to restore:

AdjustmentRemove only the Adjustment.
ReplacementRemove only the Replacement.
BothRemove both changes.

Confirm with Yes. Choosing No leaves the change untouched.

📌 Set to Default changes the selected timetable exception only. It is not the same as Reset All App Data.

🔎 8. Attendance Review

Use Check Unmarked Lectures to find eligible lectures from previous dates that still need a mark. Today's unfinished lectures are not treated as previous-day unmarked lectures.

Lecture Breakdown shows lecture-level breakdown for the active semester. The same expanded breakdown controls are available across Semesters 1–6, using each semester's isolated data.

Lecture Wise Percentage summarizes lecture-status records for each subject. The distribution uses seven outcome categories and may temporarily show In Progress for an unmarked lecture from its scheduled start until its end time:

AttendedLecture marked as attended.
Adjustment AttendedAttendance credited through an Adjustment.
Surprise TestLecture/status recorded as a Surprise Test.
Class TestLecture/status recorded as a Class Test.
Teacher AbsentTeacher was absent for the scheduled lecture.
No ClassesNo class took place.
AbsentStudent was absent.

The segmented distribution is ordered as Attended → Adjustment Attended → Surprise Test → Class Test → Teacher Absent → No Classes → Absent. The displayed Attendance percentage is calculated as (Attended + Adjustment Attended) ÷ all displayed lecture-status records × 100.

Tap the information/legend control in the Lecture Wise Percentage dialog to view the seven outcome categories and the temporary In Progress state. An unmarked lecture counts as Absent only after its scheduled end time. This behavior is available for the isolated semester environments.

🏖️ 9. Holidays & Special Days

Recorded college holidays appear as Holiday in the relevant attendance views. Protected holidays cannot be changed through normal attendance controls.

Use the attendance status and reason shown by INVICTUS for the date instead of trying to mark individual lectures on a non-college day.

📝 10. All Submitted Results

Open Semester → All Submitted Results to manage submitted results. Results are organized by semester using the app's semester dates.

Inside a semester, the Subject section shows only subjects that actually have at least one completed submitted result. Subjects with no submitted result stay hidden, and the number beside each visible subject shows its result count.

Surprise Tests and Exam Results remain separate result areas. Their existing counters, pending handling, editing, deletion rules, and submission flows continue to apply.

Tap the 🔔 Bell when you need to find Pending Results.

↕️ 11. Sorting Submitted Results

Inside a submitted-results directory, tap Sort by ▾ to change the current display order.

Newest on TopMost recently submitted first.
Oldest on TopEarliest submitted first.
Arrange in AscendingUses latest activity order.
Arrange in DescendingUses the reverse latest-activity order.

The selected sort is temporary and resets when the results directory is closed.

📈 12. Dashboard

Dashboard is your progress overview. It lets you review information without changing your records.

Weekly TimetableView the weekly schedule for the selected semester.
Monthly - Lectures StatusReview lecture status for the selected month.
Monthly ReportReview monthly attendance.
Semester - Lectures StatusReview semester lecture progress.
Semester ReportReview semester attendance.

Dashboard reporting is date-driven. Each report resolves its semester from the report date and reads that semester's isolated data. The Settings → Set Semester preference does not change the Dashboard's reporting context.

🎓 13. Semester System

INVICTUS maintains separate environments for Semesters 1–6. Each semester has its own working period, attendance/lecture data, subjects, timetable, percentage tracking, surprise tests, and exam results.

All six semesters remain directly selectable through Settings → Account → Set Semester. A semester is not hidden simply because its configured START date is in the future.

The selected semester is the active semester for semester-scoped areas such as Lecture Breakdown, All Submitted Results, and Weekly Timetable. Switching the selected semester does not merge or share the underlying semester data.

Semester 1 uses its configured 08/08/2026–31/01/2027 working period. The other semesters retain their own configured periods.

👤 14. Profile & Account

Open Settings → Account to manage your profile and account.

Profile Photo — Upload, view, or delete your photo. Deletion requires confirmation.

Change Name / Change Gmail — Update the corresponding account information.

Set Semester — Select Semester 1–6 as your active semester. The old All option is no longer available.

Log out — End the current session.

⚙️ 15. Settings

Settings contains the app's account, app, notification, data, display, security, appearance, help, and information controls.

AccountProfile, account details, Set Semester, and Log out.
AppRefresh/update controls and Persistent Saving for your College Joining Date.
NotificationsTurn available attendance and lecture reminders on or off.
DataExport, import, or reset app data.
SizeAdjust Font Size and Display Size.
SecurityManage the available Student ID and Password options.
AppearanceChoose Light or Dark mode.
Help / AboutOpen this guide or view information about INVICTUS.

🔔 16. Notification Centre

Tap the bell to open the Notification Centre.

Submit Your Attendance can remind you when today's attendance has not been submitted during the applicable window.

Mark Your Today Lecture can remind you when an eligible lecture has ended and still needs to be marked.

Use Settings → Notifications to control the available reminders. INVICTUS notifications are shown inside the app.

💾 17. Backup & Reset

Export Data creates a backup of your INVICTUS records. Import Data restores data from a compatible INVICTUS backup.

Your saved Set Semester preference is included in the app's backup/reset handling.

⚠️ Reset All App Data clears your saved application records and resets most app preferences. Your College Joining Date is retained when Settings → App → Persistent Saving is ON and cleared when it is OFF. Use reset only when you intentionally want to start again.

💡 18. Quick Daily Routine

1. Record the day's attendance in Submit Your Attendance.

2. If INVICTUS asks you to resolve previous unresolved attendance, complete the semester-wise resolution flow before continuing.

3. Open Daily Timetable and mark each completed lecture.

4. Use Schedule Exception → Set Adjustment only when you attended a different subject during a scheduled period.

5. Use Schedule Exception → Set Replacement when the lecture occupying a slot actually changed.

6. Check the bell for reminders and pending results.

7. Review Dashboard, Lecture Breakdown, and Lecture Wise Percentage to understand your progress.

✅ 19. You're Ready to Use INVICTUS

Attendance records your college day, Semester handles your timetable and results, Dashboard shows date-driven progress reports, and Settings manages your account and app preferences.

For the most accurate workflow, remember: daily attendance → resolve previous pending attendance when requested → lecture marking → exceptions only when needed → check results and progress.

Whenever you need help, open Help → User Guide and return to the relevant section.
