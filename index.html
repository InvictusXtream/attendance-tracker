INVICTUS User Guide

Everything you need to use the app confidently.
New to INVICTUS? Use Quick Start first. Then use the sections below whenever you need help with a specific feature.

🚀 Quick Start

1. Mark today's attendanceAttendance → Submit Your Attendance
2. See today's classesSemester → Daily Timetable
3. Mark lecture attendanceSemester → Daily Timetable → tap the 3 dots on a lecture
4. Enter a test or exam resultSemester → All Sumbitted Results
5. Check unfinished resultsSemester → All Sumbitted Results → 🔔 Bell → Pending Results
6. View timetable and reportsDashboard

📊 Attendance

Submit Your Attendance — Create a new attendance entry. Select Present, Absent, Holiday, or Blank and complete the required reason/comment where applicable. Present requires a reason.

Select Reason — Present, Absent, and Blank require a reason. Present may use Regular College Day, Exam Day, or Other — Custom Reason as provided by the app.

Regular College Day is a valid Present path but is not printed as a reason in Attendance History.

Edit Your Attendance — Change an existing attendance record when the current attendance rules allow it.

Attendance History — Tap Show to view saved submissions. Protected built-in Holiday records may show Automatic instead of a submission time.

Calendar — Use the attendance calendar or month picker to move to another available month/date.

⏰ Present attendance has an on-time submission window. A valid Present submission after that window is recorded as a Late Submission.

📚 Semester

Daily Timetable — View scheduled lectures for the selected date. Swipe left/right to move between days.

Lecture Attendance — Tap a lecture’s 3 dots to open its attendance dialogue. Only one lecture attendance dialogue is active at a time.

The dialogue provides Attended, Absent, Teacher Absent, and No Classes.

Attended — Choose either Current — Selected Lecture or Adjustment Period.

Adjustment Period — Use this when you attended a different subject instead of the lecture shown in the timetable. A dedicated dialogue lets you choose the replacement from Subjects, Lab, or Others.

With an adjustment, the original timetable lecture remains Teacher Absent for lecture analytics while the selected subject receives the attendance credit.

  • Counts as one attended lecture.
  • Does not add an extra Lecture Reached.
  • Contributes to the selected subject's percentage.
  • Appears separately as Adjustment Period.
  • Can be changed later without creating duplicate credit.

Semester Calendar — Jump to another date. A date change is confirmed before the timetable changes.

Check Unmarked Lectures — Find eligible lectures still unmarked on previous dates and jump directly to their dates. Today is not included.

Lecture Wise Percentage — View subject-wise lecture attendance percentages.

Lectures breakdown — Open the Semester card and choose an available semester. Filters include Attended, Absent, Teacher Absent, No Classes, and Adjustment Period.

Adjustment Period is separate from normal Attended. Its credit is counted once in Total Lectures Attended and contributes to the selected subject's percentage, while the original timetable lecture remains Teacher Absent.

Semester content unlocks progressively according to its configured start date.

📝 Results

All Sumbitted Results contains Subject, Surprise Tests, and Exam Results.

Subject results — Open a subject to view submitted results. Existing results can be edited or deleted where allowed. After a successful deletion, the open result report closes and the results directory refreshes immediately.

Surprise Tests — Add and manage surprise-test results using their separate result flow.

Class Tests — Total Marks must be entered first. Marks Gained becomes available after a valid Total Marks value is entered.

Exam Results — Exam Day attendance can create linked pending exam-result entries. Complete the required exam details and confirm before final submission.

Start and End Time use separate hour/minute inputs with AM/PM. Use Next to open Confirm Submission.

  • Yes submits and returns to the relevant existing results destination.
  • No returns to the previously opened dialogue stack with the entered draft restored.

Pending Results 🔔 — A red indicator appears when pending Class Test or Surprise Test results exist. Tap the bell to open Pending Results; pending cards open directly for editing.

🔒 Successfully submitted Exam Results cannot be deleted.

📈 Dashboard

Weekly Timetable — Open the card, then choose Semester 1–6 to view the corresponding timetable content available to you.

Monthly - Lectures Status — Review monthly lecture progress and status.

Monthly Report — Review monthly attendance totals and reporting.

Semester - Lectures Status — Review lecture progress across a semester.

Semester Report — Review attendance reporting across a semester.

↕️ Dashboard cards are mutually exclusive where applicable, and opening an expanded card automatically brings it into view. When space allows, the next card header remains visible for quick switching.

⚙️ Settings

Account — Manage your profile and account actions, including logout.

App — Refresh applied changes or check for an available update.

Data — Export a backup, import an INVICTUS backup, or reset app data.

Size — Adjust Font Size and Display Size. Changes are saved locally.

Security — Manage Student ID and Password.

Appearance — Switch between Light and Dark appearance.

Help — Open this User Guide.

About — View INVICTUS information and credits.

Only one expandable Settings category is open at a time. The active category is highlighted with the INVICTUS purple border.

🔔 Notifications

Open the in-app Notification Centre using the bell.

Submit Your Attendance — Appears between 08:30 AM and 09:30 AM when today's attendance has not been submitted.

Mark Your Today Lecture — Appears for today when attendance is Present + Regular College Day, after an eligible timetable lecture has ended, and remains until that lecture is marked.

🔔 Notifications are in-app only; they do not send browser, Android, or other system notifications.

💾 Data & Safety

Export Data — Create a backup of your INVICTUS app data. Keep a recent backup before major changes or a reset.

Import Data — Restore data from a compatible INVICTUS backup. Do not edit backup files manually.

⚠️ Reset All App Data permanently deletes submitted Attendance & Semester records. Use it only when you intentionally want to start with a clean app state.

💡 Useful Tips

• Tap a card when it is the action itself; many cards open their content directly without a separate Open button.

• 3 dots on a lecture open its attendance actions, and only one lecture attendance dialogue is active at a time.

• Adjustment Period means you attended a different subject during the selected timetable slot.

• The original timetable lecture remains Teacher Absent for lecture analytics when an adjustment is used.

• Adjustment Period is counted once and is separate from the normal Attended filter.

• A second dialog may appear above the current one when a feature requires a dedicated selection step. Cancel/Close normally returns to the previous dialog.

• Long lists inside dialogs scroll independently. If the dialog header stays fixed, scroll the list area itself.

• The top navigation stays available while you scroll through a page.
